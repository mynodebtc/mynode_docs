# Changing your Password

MyNode asks you to set your own password the first time you log in. You can change it at any time from the settings page. The same password is used for the web interface, SSH, and sensitive actions on your device.

First, go to the settings page. Next, fill out your current password.

<center>
  <figure>
    <img src="/images/device/password.png" alt="Change Password section of the MyNode settings page with Current Password, Password and Repeat Password fields" style="width: 500px">
  </figure>
</center>

Finally, enter a new password, repeat it and click Save.

Your password has now been updated!
